# משחק בלק ז'ק

---

## תיאור משחק

תיאור המשחק - שחקן נוצר אוטומטי אם השחקן גלש בדפדפן אחר או שלו קיים ב LocalStorage

בפעם הראשונה של השחקן אז המשחק מתחיל עם chips של 1000.
עכשיו המשחק מתחיל שלכל אחד יש 2 קלפים לשחקן פתוח 2 הקלפים ולדילר מקבל קלף אחד וקלף מכוסה

המנצח הוא מי שליריב שלו יש יותר ממספר 21. ומקבל את סכום ההימור כפול 2
ויש גם אפשרות לתיקו אם לשתיהם יש את אותם קלפים.

עכשיו יש שתי אפשרויות לשחקן: אחד לפתוח קלף או לומר לדילר לפתוח ואז הוא פותח עד שהוא מגיע לסכום של 17 כולל הקלף המכוסה (השחקן לא יודע את המספר שיש בקלף המכוסה).
שחקן יכול לפתוח קלפים עד שהסכום שלו יותר מ 21.

עכשיו אם הדילר הגיע לסכום בין 17 - 21, המנצח הוא מי שיש לו סכום הכי גדול והכי קרוב ל-21

## שימוש סביבה

המשחק נכתב ב: javaScript, html, css
שמירת נתונים: Supabase(שחקן) & MongoDB(סבב משחק)
(משתמש בשתי סוגי DATABASES כדי לתרגל, אבל בעיקרון היה מספיק MongoDB)
שימוש בספריות:
mongodb, supabase, express, (zod)

## מבנה טבלאות

שחקן:

| שם        | סוג                           | מידע |
| --------- | ----------------------------- | ---- |
| id        | מחרוזת הגדרת אוטומטית ויחודית |      |
| chips     | מספר שלם ואי שלילי (>=0)      |      |
| createdAt | יצירה אוטומטית                |      |

---

סבב משחק:

| שם          | סוג                                                                                                   |
| ----------- | ----------------------------------------------------------------------------------------------------- |
| id          | מחרוזת הגדרת אוטומטית במונגו                                                                          |
| playerId    | מזהה של השחקן מהטבלה הקודמת                                                                           |
| bet         | סכום ההימור                                                                                           |
| playerCards | מערך של אוביקט עם השדות של הקלף והסוג                                                                 |
| dealerCards | מערך של אוביקט עם השדות של הקלף והסוג                                                                 |
| status      | אחד משתי האפשרויות: ["in_progress", "player-bust", "dealer_bust", "player_win", "dealer_win", "push"] |
| createdAt   |                                                                                                       |
